# Extension Points

Add role policy through `PanelRole`, plan objectives, evaluator schema, and controller rules together. Add candidate-callable tools through the shared tool union, explicit command boundary, confirmation policy for writes, audit record, report projection, and tests. Add modalities by updating public types, session state, candidate polling, and workspace rendering.

`RoundTablePanel` is the current visual extension and must remain presentation-only. Future avatar/video providers must be opt-in, independently failure-tolerant, clearly disclosed, and incapable of supplying interview evidence. ATS integration, multilingual speech, human takeover, and candidate accounts are later extensions. Biometric inference must never produce an automatic rejection.

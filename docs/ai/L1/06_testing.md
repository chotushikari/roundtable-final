# Testing

Workspace regression checks required-code versus design scenarios and voice-command classification. Recruiter voice tests cover English/Hinglish job, seniority, candidate name, and spoken-email collection, including multi-turn clarification before any mutation. Live rehearsal must also verify animated automatic opening, reduced motion, compact audio controls, draft retention across minimization, autosaved voice review, high-contrast/clickable canvas controls, and E2B result delivery. E2B runs functional cases for selected demo tasks and syntax/runtime validation for unknown questions.

Run `npm test`, `npm run lint`, `npm run typecheck`, `npm run verify:api`, and `npm run build`. `npm run verify` additionally requires a complete `.env.local` through `doctor`.

Assessment tests exercise oversized multilingual history, byte ceilings including the wire schema, invalid evidence IDs, preservation of full ratings/evidence, conservative code/canvas signals resolving to immutable artifact-version IDs, and a complete five-role demo where Hiring Manager, Customer, and Behavioural answers plus Technical/Product workspaces all resolve to their correct panel views. Provider tests simulate cooldown across JSON/speech calls and retry-window expiry without network access. The separate optional provider smoke script checks one real request with synthetic evidence.

Offline demo regression runs five answers through durable state with pause/repeat, simultaneous duplicate requests, fragmented introductions/technical/behavioural answers, and unheard questions for every role. It verifies all-role analysis, prevents premature closing, and checks that a technical strength plus missing customer impact can prioritize the unasked Product role. The live gate requires real Agora join/RTC/RTM/renewal proof, five-role completion after the closing audio, published duration limit (ten minutes for new dashboard demos), pause/repeat/readiness checks, 20 barge-in attempts with p95 stop time, impaired-network recovery, SSE/audio latency, deployed Supabase RLS tests, and E2B isolation checks. Allow roughly 30 seconds per answer and record actual timing. Verify question receipts after a full question, after interruption/repeat, and after reconnect; partial phrases must not skip Product or Customer. Offline success must not be represented as live success.

Intern regressions cover both workspace modalities across five roles, missing-scenario fallback and checkpoint acknowledgements without draft visibility. They include compact two-line ascending-sort implementations, “updated” voice review requests, task-specific hints, and language-choice replies. Live rehearsal must verify Python sandbox availability, language reload persistence, specific spoken review, automatic workspace handoff, and coding/design timing.

Camera interaction regression covers consent refusal, camera-unavailable handling, challenge expiry, the two-review limit, and storage of a result without raw media. A live check should verify that the random gesture-and-phrase prompt is shown, capture ends promptly, and the outcome remains separate from interview scoring and company live status.

Company report tests cover duration calculation, tenant-safe endpoint authorization, final evidence-to-transcript mapping, must-ask coverage, workspace metadata extraction, and the permanent human-review requirement. A non-completed session must return status only, not partial interview content.

Legacy integration unit tests may remain for migration compatibility, but no external issue-tracker workflow is exposed by the dashboard or candidate voice controller.
